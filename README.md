# soat-vehicle-sales

Serviço de vendas da plataforma de revenda de veículos. Este repositório será responsável pelas listagens, compras, pagamentos e webhook, utilizando um banco de dados segregado e comunicação HTTP com o serviço principal.

As decisões de escopo, domínio, arquitetura e integração estão documentadas no [documento de definição do projeto](https://github.com/igortessaro/soat-vehicle-management/blob/main/docs/PROJECT-DEFINITION.md).
